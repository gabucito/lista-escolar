# Responsive editor refinement

`01-responsive-editor.png` is a design reference generated with the built-in
image generation tool on 2026-11-10. It supplements the approved interface
concepts; the product specification remains authoritative.

The first rendered mobile editor placed catalog, custom-item and PDF controls
before the school details. The refinement brings the course information and
supplies forward, adds short in-page navigation, and keeps save/preview/publish
actions reachable. Published lists also need reachable PDF actions on a phone.
Desktop retains the established cream, navy and sage direction.

Incidental mockup navigation and PDF layout names are illustrative. The actual
application keeps its existing routes and the three approved PDF layouts.
