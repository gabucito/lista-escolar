# Shared category and attribute sidenav

Actual browser captures of the requested navigation change, 2026-11-10.
Open [the gallery](index.html). Categories appear first; choosing one switches
the same panel to its attributes. Catálogo and the persistent category-back
control return to category selection without changing current filters.
Desktop results stay beside the panel. Mobile preserves panel view, focus and
scroll across close/reopen and has an explicit results action.

All screenshots use disposable QA accounts and databases. No catalog schema or
migration changes were needed. See [validation](../../../docs/VALIDATION.md).
